ATR

Architecture & agent thinking

Clear orchestration separates decisions from tools.

The controller owns routing, dependency-aware workflows, retries, and trace construction. Tools implement one small contract; persistence and transport remain separate.

This is a deliberately deterministic orchestration layer: transparent today, and ready for an LLM classifier behind the same interface later.
01 Interpret task + score registered tools
02 Coordinate independent or dependent sub-tasks
03 Execute safely with bounded fallback
04 Stream trace + persist auditable state
